気づき

投稿は加点の入口で、一番遅い
  • POST /api/posts は平均 2.1 秒、p95 5.1 秒です。
  • 友達フィード 10 点は、投稿期間が終わる前の検証が条件です。
  • 遅いと、期間内に検証へ進めず取りこぼします。
画像とフィードが呼出数の中心
  • images は 4,627 回、feeds は 2,553 回です。
  • 配点は 2 点と 1 点で、上限があります。
  • 上限を超えた呼出は加点されません。速さの効果は、1 走行で回せる周回数に出ます。
エクスポートは 1 回 20 点
  • 74 回で平均 1.3 秒、p95 3.6 秒です。
  • 履歴と画像が初期データと違うと FAIL です。
  • 高速化するときは、結果を変えないことが最優先です。
通知は SSE で時間が長いだけ
  • 平均 15.6 秒の合計時間は、接続を保っている時間です。
  • NewRelic の合計時間ランキングでは 1 位に出ますが、遅さを示しません。
  • 見るときは除外して順位を読みます。
NewRelic で分けられない行
  • friend-requests/:action は accept・reject・cancel を合算します。
  • memories は月単位と前回確認を合算します。
  • DELETE /api/blocks は 24 時間で 0 回でした。
