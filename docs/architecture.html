ISUReal 競技環境

TL;DR

  • 写真 SNS の ISUReal を、地域固定の App 3 台と共有 DB 1 台で動かしている。
  • 全通信が Router を通り、DB までの往復は asia1 が 1.2 ms、europe1 と america1 が 101 ms。
  • スコア倍率 1.5 の 2 地域が、いちばん遅い経路に乗っている。
  • App 同士は通信しない。共有する状態はすべて asia2 の PostgreSQL にある。

変更できる

守る

  • 固定リージョンと Router 経由の通信。遅延と帯域制限は回避しない。
  • 書き込み後の読み取りは、地域をまたいでも結果を反映する。
  • 猶予は削除した投稿の画像の 5 秒だけ。
  • 再起動後もデータを読める状態にする。追試で確認される。
  • sql/001-schema.sql は流さない。全テーブルを DROP して、初期データを戻せなくなる。
